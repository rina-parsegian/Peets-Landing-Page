# Peet's Coffee Landing Page

A responsive recreation of a Peet's Coffee webpage built with HTML, CSS, and JavaScript.

## Live Demo

[View the live Peet's Coffee Landing Page](https://rina-parsegian.github.io/Peets-Landing-Page/)

## About the Project

I built this project to practice recreating a real world webpage from a visual reference and translating an existing design into responsive front-end code.

The goal was to strengthen my ability to structure a complete webpage, recreate layouts and visual elements, build responsive designs, and add basic JavaScript functionality.

After completing the initial build, I revisited the project to refactor the code and improve its organization, responsiveness, accessibility, and maintainability.

## What I Practiced

- Semantic HTML
- Responsive layouts using Flexbox
- Reusable CSS classes and BEM-style naming
- Responsive images
- CSS media queries
- Mobile and desktop navigation
- Hover states and UI interactions
- Mobile navigation with JavaScript
- Dynamic copyright year with JavaScript
- Basic accessibility practices
- Basic on-page SEO metadata
- Refactoring and simplifying existing code
- Git and GitHub workflow

## Refactoring & Improvements

After completing the first version of the page, I reviewed the HTML and CSS to look for opportunities to simplify and improve the code.

Some of the improvements included:

- Replacing repetitive classes with reusable component classes
- Improving BEM-style class naming
- Removing unused and redundant CSS
- Using Flexbox instead of unnecessary positioning where appropriate
- Simplifying responsive styles and media queries
- Improving image behavior across screen sizes
- Adding accessible labels to interactive elements
- Adding a dynamic copyright year with JavaScript
- Adding a descriptive page title, meta description, and canonical URL

## What I Learned

This project helped me become more comfortable breaking a full webpage into individual sections and translating a visual design into working code.

The refactoring process also reinforced that working code can still be improved. I practiced reviewing existing CSS to determine whether each rule was necessary, whether styles could be reused, and whether a layout could be made simpler and easier to maintain.

I also gained more practice testing responsive layouts across different screen sizes and troubleshooting issues caused by styles that prevented elements from shrinking properly.
